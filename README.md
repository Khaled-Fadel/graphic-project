# Colored House – OpenGL (GLUT)

This project demonstrates a simple 2D house drawn using **OpenGL** and **GLUT**,
featuring **per-vertex coloring** to achieve smooth color interpolation.

## 🏠 Description
- House body drawn using `GL_QUADS`
- Roof drawn using `GL_TRIANGLES`
- Uses orthographic 2D projection (`gluOrtho2D`)
- Per-vertex coloring with color interpolation
- Double buffering enabled to avoid flickering

## 🛠 Requirements
- OpenGL
- GLUT / FreeGLUT
- C/C++ Compiler

## ▶ Compile

Make sure OpenGL and GLUT (or FreeGLUT) are properly installed and linked.
